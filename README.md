Программа поддерживает:

- сложение матриц;
- вычитание матриц;
- умножение матриц;
- деление матриц;
- транспонирование матрицы;
- вычисление определителя;
- нахождение обратной матрицы.

Определитель вычисляется методом Гаусса.

Деление матриц выполняется по формуле:

A / B = A * B⁻¹`

 Структура проекта

- `Complex.java` — класс комплексного числа
- `ComplexMatrix.java` — класс матрицы комплексных чисел
- `Main.java` — консольное меню программы
- `Test.java` — проверка операций с матрицами
